# Аким на 5 часов

Лёгкий симулятор управления Астаной: реальная карта города, пять решений и результат через два года.
**Python 3.10+ · обычные HTML/CSS/ES modules · без npm и сборки.**

## Запуск

```bash
python app.py
```

Откройте **http://127.0.0.1:8000**. Если порт занят: `python app.py --port 8001`.
После обновления сервер нужно перезапустить: список статических маршрутов изменился.
Карта использует интернет. Для расчётов, выбора проектов и резервной схемы интернет не нужен.

## Интерфейс

- Карта занимает весь экран. Сверху — качество жизни, **оставшийся** бюджет и количество решений.
- **Карта:** наведение показывает район и оценку; клик открывает небольшую карточку с тремя приоритетными проблемами. Все десять показателей доступны по явному раскрытию.
- **Решения:** фильтр направлений, назначение района, компактный список выбранных проектов, валидация и запуск. На старте район не выбран.
- **Пульс:** существующие синтетические обращения в скрываемой панели. Пока это исходный/финальный срез, а не новый поток событий; выдуманных дат и непрочитанных событий нет.
- **Итоги:** изменение оценки, основные результаты и переключатель «До / После». Он меняет игровые слои и показатели, а не реальные здания или дороги на базовой карте.
- Альтернативный сценарий, реакции жителей и пресс-конференция находятся в раскрываемых блоках.
- **Советник:** короткая подсказка по данным выбранного района; действия фокусируют карту или открывают подходящее направление решений. Используются существующие AI-реакции, если они уже получены.
- Одна основная панель открыта одновременно. На телефоне она становится нижним листом.
- Темы меняют интерфейс, базовую карту и игровые слои. Предпочтение хранится в `akim-theme-v1`; при первом запуске используется системная тема.
- Черновик плана по-прежнему сохраняется в `akim-map-plan-v1`. Импорт, экспорт, демо-план и сброс доступны через меню `···`.
- Кнопка выбора района в группе управления картой доступна с клавиатуры. Escape закрывает контекстную панель; анимация учитывает `prefers-reduced-motion`.

## Карта и география

**MapLibre GL JS 5.6.2**, локальная CSP-сборка и отдельный worker, находятся в
`static/vendor/maplibre/`. Лицензия поставляется рядом. Зависимость зафиксирована;
приложение не загружает JavaScript с CDN. Восстановить эти файлы можно командой:

```bash
python tools/fetch_map_assets.py
```

Провайдер — **OpenFreeMap**, векторные данные OpenStreetMap. Настройки камеры,
URL светлого/тёмного стиля и поля высоты зданий изолированы в `static/map-provider.js`.
Стили Positron/Dark дополняются палитрой из CSS-переменных `--map-*`.
Атрибуция провайдера остаётся видимой. Google Maps и извлечённые данные Google не используются.

- [OpenFreeMap](https://openfreemap.org/) и [настройка стилей](https://openfreemap.org/quick_start/)
- [MapLibre: объёмные здания](https://maplibre.org/maplibre-gl-js/docs/examples/display-buildings-in-3d/)

`static/map-adapter.js` владеет единственным экземпляром MapLibre. Переключение тем,
видов и 2D/3D не пересоздаёт карту. После загрузки нового стиля адаптер восстанавливает
игровые источники, слои и выделение из текущего состояния. При 3D меняются наклон
камеры и слой экструзии. Объёмные здания видны на близком масштабе (от zoom 13);
используется доступная высота провайдера, отсутствующая высота не выдумывается.

**Границы районов временные и приблизительные.** В репозитории не было проверенных
административных полигонов. `static/game-geography.js` содержит вручную заданные
городские сектора GeoJSON со стабильными ID и точными `backendName` для пяти
районов модели. Это не официальная административная карта. Позже этот файл можно
заменить проверенным лицензированным набором без изменения симулятора.

Позиции обращений и проектов — представительные точки районов, не адреса жителей
и не настоящие строительные площадки. Городская мера показывается одним отдельным
маркером, чтобы не перегружать карту. Проблемы кластеризуются при отдалении.
Небольшие области вокруг активных проектов — условная визуализация, не географическая
оценка зоны воздействия.

Симулятор не зависит от провайдера: базовая карта, игровые полигоны и численная модель
разделены. При смене провайдера обновите также точный список разрешённых источников
в CSP в `app.py`; общие разрешения `*` не нужны.

## Сеть и резервный режим

Если стиль или тайлы недоступны, интерфейс показывает компактное сообщение с
повторной загрузкой и переходом на схему. Выбор проектов, черновик и симуляция
продолжают работать. При недоступном стиле остаются локальные игровые слои, если
WebGL поддерживается. Тайлы, подписи и высоты полностью офлайн не поставляются.

Старый `static/city-map.js` сохранён без изменения как временный SVG-рендерер.
Можно открыть **http://127.0.0.1:8000/?legacyMap=1** или нажать «Открыть схему»
при ошибке. Это схематичная резервная карта; переключатель реального 3D в ней отключён.
«Повторить» возвращает к реальной карте без потери плана.

## Время и расчёты

`city_simulator.py` и правила не изменены. Каждый расчёт начинается с исходных значений.

- Ровно 5 уникальных мероприятий, стоимость ≤ 100, не более 2 одного направления.
- M1/M3 несовместимы везде; M4/M7 и M5/M13 — в одном районе.
- Эффект: `base_effect × (8 - lag) / 8`.
- Городская мера применяется полностью к каждому району.
- Синергии фиксированы и не масштабируются лагом.
- После суммирования значения ограничиваются `[0, 100]`.
- `D_d = sum(weight × indicator)`; `D_avg = sum(population_share × D_d)`.
- `N_crit` — количество пар «район / показатель» строго ниже 40.
- `Score = 0.7 × D_avg + 0.3 × min(D_d) - N_crit`.

**Квартальная шкала — визуальное воспроизведение.** Проект активируется в квартале
`lag + 1` (например, M8 с лагом 3 — в Q4). На экране может появиться сообщение о
запуске и измениться маркер. Численные оценки остаются исходными до завершения Q8,
когда интерфейс применяет окончательный ответ Python. Интерполяции Q1–Q7 нет.

Контрольный план: M7, M8, M10 в Нуре; M12 для города; M5 в Сарыарке.

| Величина | До | После |
| --- | ---: | ---: |
| D_avg | 56.8624 | 58.0776 |
| Минимальный балл района | 49.18 | 52.9625 |
| N_crit | 2 | 0 |
| Quality of Life | 52.55768 | **56.54307** |

Стоимость **95**, остаток **5**, прирост **3.98539**. В UI числа округляются до двух знаков.

```bash
python city_simulator.py --self-check
python city_simulator.py --plan example_plan.json
python city_simulator.py --plan example_plan.json --prompt
```

## Существующая интеграция AI

В этом этапе AI backend и логика альтернатив не изменялись. Ключи остаются на сервере.

```powershell
$env:OPENAI_API_KEY = 'ваш-ключ'
$env:LLM_MODEL = 'идентификатор-модели'
$env:LLM_BASE_URL = 'https://api.openai.com/v1'
python app.py
```

Также поддерживается `LLM_API_KEY` с приоритетом над `OPENAI_API_KEY`. `.env`
автоматически не загружается. Провайдер должен поддерживать Chat Completions с
`response_format: json_schema`. Без настроек или при ошибках используются локальные
тексты. AI меняет только повествование; числа и связи с районами вычисляет Python.
Пресс-конференция не влияет на Score. Новый AI-поток событий пока не реализован.

## API и файлы

POST-контракты сохранены: `/api/validate`, `/api/simulate`, `/api/alternative`,
`/api/compare`, `/api/report`, `/api/ai/appeals`, `/api/ai/result`, `/api/ai/feedback`.
`GET /api/catalog` возвращает прежний каталог. Добавлены только статические маршруты
и разрешения CSP для OpenFreeMap и локального worker. Сервер по умолчанию локальный.

новых ресурсов, MIME worker и ограничений CSP. Поэтому ожидаемый текущий итог —
**38/39 проходят с тем же исходным падением**, без новых регрессий.

Для browser smoke нужны **Chrome и Node 22+** только в окружении проверки.
Пакеты npm и `websocket-client` не требуются. Используйте отдельный профиль:
тест сбрасывает его черновик и тему, сохраняет скриншоты в `.browser-check/`.

Терминал 1:

```powershell
python app.py --port 8001
```

Терминал 2 (PowerShell, из корня проекта):

```powershell

python tools/check_browser.py http://127.0.0.1:8001 9222
```

Проверяются реальная карта, отсутствие открытой панели при старте, выбор района,
раскрытие метрик, ручной план, бюджет, конфликты, защита от устаревшей валидации,
Q1–Q8 без промежуточного Score, финал 56.54, «До / После», альтернативы,
импорт/экспорт, светлая/тёмная темы и 2D/3D на одном экземпляре карты, мобильный вид,
клавиатура, reduced motion, искусственная блокировка тайлов, схема и восстановление.
Проверка нормальной карты требует доступности OpenFreeMap. Скриншоты и тестовый
профиль не включаются в Git.
